Welcome! Alfred is a simple chatbot built in python using the modules:
	1. webbrowser
	2. wikipedia
	3. sys
	4. random
Alfred can:
	1. Open any websiste
	2. Google for anything
	3. Search for pages on wikipedia
	4. Can tell you jokes,
	5. Responds on: hi, how are you?, who are you?
	6. Has a simple to-do list feature.

Check the GUIDE file for installation instructions.
